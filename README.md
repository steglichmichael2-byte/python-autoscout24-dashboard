# Python AutoScout24 Dashboard

Interaktives Python-Dashboard zur Analyse von Gebrauchtwagenpreisen und Fahrzeugdaten.

## Projektübersicht

Das Projekt ist ein interaktives Dashboard zur Analyse von Gebrauchtwagendaten.

Mit verschiedenen Filtern können Fahrzeugdaten nach Marke, Kraftstoffart und Baujahr untersucht werden. Die Kennzahlen, Diagramme und die Fahrzeugtabelle reagieren dynamisch auf die ausgewählten Filter.

## Projektziel

Ziel des Projekts ist es, Gebrauchtwagendaten übersichtlich aufzubereiten und wichtige Zusammenhänge zwischen Fahrzeugpreis, Kilometerstand, Marke, Baujahr und weiteren Fahrzeugmerkmalen sichtbar zu machen.

## Funktionen

- Filter nach Fahrzeugmarke
- Filter nach Kraftstoffart
- Filter nach Baujahr
- Dynamische Aktualisierung der Kennzahlen
- Anzahl der gefilterten Fahrzeuge
- Berechnung des Durchschnittspreises
- Analyse des durchschnittlichen Kilometerstands
- Analyse der durchschnittlichen Motorleistung in PS
- Preis-Kilometer-Analyse
- Darstellung der Preisverteilung
- Vergleich von Schalt- und Automatikgetrieben
- Top-15-Marken nach Durchschnittspreis
- Dynamisch gefilterte Fahrzeugtabelle

## Verwendete Technologien

- Python
- Pandas
- Plotly
- Dash

- Durchschnittspreis
